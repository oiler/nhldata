# v3.0.0: Goalies in the browser

Released 2026-07-19. The browser gained a goalie index, a goalie page, and a goalie environment section on each team page, read from a new `goalies.db`. `CHANGELOG.md` section "3.0.0" lists what changed.

## This folder

This folder was assembled on 2026-11-17 from `docs/plans/` by `git mv` and a literal replacement of the old paths. The release shipped before release folders existed, so this record has no design section, human test, or close-out.

| Path | What it is |
|---|---|
| `specs/2026-07-18-goalie-browser-design.md` | The design for the goalie pages |
| `plans/2026-07-19-goalie-browser-plan.md` | The implementation plan |

The pages show results of the goalie evaluation research. That research's design, plans, and reports are in `research/goalies/docs/`.
